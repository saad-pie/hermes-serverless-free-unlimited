API Documentation & Model Fetching

Drop-in OpenAI compatible zero-cost API endpoints including live model list retrieval.

1. Base Endpoints

GET /v1/models — Standard OpenAI compatible models list endpoint
GET /api/models — Detailed diagnostic and models registry endpoint

Provider API keys (Atria, Unorouter, AIHubMix, Gemini) are stored securely server-side in backend environment variables. Clients only need any dummy key (e.g. antigravity-free).

2. Fetch Models (cURL)

curl -s http://localhost:3000/v1/models \
  -H "Authorization: Bearer antigravity-free"

3. Fetch Models (JavaScript / OpenAI SDK)

import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "antigravity-free",
  baseURL: "/v1"
});

const models = await openai.models.list();
for await (const model of models) {
  console.log(model.id);
}

4. Chat Completion (Atria Dawn Preview)

curl /v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer antigravity-free" \
  -d '{
    "model": "Atria-Dawn-Preview",
    "messages": [{"role": "user", "content": "hi"}]
  }'
