API Documentation & Integration

Drop-in OpenAI compatible zero-cost API endpoint integration hosted at https://antigravity-seven-delta.vercel.app/v1.

1. Base URL

https://antigravity-seven-delta.vercel.app/v1

Provider API keys (Atria, Unorouter, AIHubMix, Gemini) are stored securely server-side in backend environment variables. Clients only need any dummy key (e.g. antigravity-free).

2. Fetch Models

curl -s https://antigravity-seven-delta.vercel.app/v1/models \
  -H "Authorization: Bearer antigravity-free"

3. Chat Completion (cURL)

curl https://antigravity-seven-delta.vercel.app/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer antigravity-free" \
  -d '{
    "model": "Atria-Dawn-Preview",
    "messages": [{"role": "user", "content": "hi"}]
  }'

4. JavaScript / OpenAI SDK Integration

import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "antigravity-free",
  baseURL: "https://antigravity-seven-delta.vercel.app/v1"
});

const response = await openai.chat.completions.create({
  model: "Atria-Dawn-Preview",
  messages: [{ role: "user", content: "hi" }],
});

console.log(response.choices[0].message.content);
