API Documentation & Atria Integration

Drop-in OpenAI compatible zero-cost API endpoint integration featuring Atria-Dawn-Preview.

1. Base Endpoint

/v1

2. cURL Example (Atria Dawn Preview)

curl /v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer atr_xxx" \
  -d '{
    "model": "Atria-Dawn-Preview",
    "messages": [{"role": "user", "content": "hi"}]
  }'

3. JavaScript / OpenAI SDK

import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "atr_xxx",
  baseURL: "/v1"
});

const response = await openai.chat.completions.create({
  model: "Atria-Dawn-Preview",
  messages: [{ role: "user", content: "hi" }],
});

console.log(response.choices[0].message.content);
