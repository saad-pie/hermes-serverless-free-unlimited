API Integration Guide

Use your gateway endpoint as a drop-in OpenAI replacement anywhere.

1. Base Endpoint URL

https://antigravity-seven-delta.vercel.app/v1

2. cURL Example

curl https://antigravity-seven-delta.vercel.app/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ANY_KEY_OR_PLACEHOLDER" \
  -d '{
    "model": "gemini-2.5-flash",
    "messages": [{"role": "user", "content": "Hello! Give me a quick system check."}]
  }'

3. JavaScript / OpenAI SDK Client Setup

import OpenAI from "openai";

const openai = new OpenAI({
  apiKey: "any-placeholder-string",
  baseURL: "https://antigravity-seven-delta.vercel.app/v1"
});

const response = await openai.chat.completions.create({
  model: "gemini-2.5-flash",
  messages: [{ role: "user", content: "Write a haiku about high speed routing." }],
});

console.log(response.choices[0].message.content);
